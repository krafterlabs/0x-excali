# Security Policy

## Supported Versions

We currently support the latest released version of 0x-excali only.

## Reporting a Vulnerability

If you discover a security vulnerability, please do **not** publicly disclose it. Instead:
- If GitHub Security Advisories are enabled for this repository, please open a private security advisory.
- Otherwise, please open a new issue with minimal sensitive details (e.g. "Security concern regarding X module, please contact me").

We operate on a "best effort" basis to respond to and triage security concerns. Please do not publish exploit details until maintainers have had an opportunity to address the issue.
